# VIDHI - Tamil Doom

A browser-playable Doom-style FPS built from scratch with HTML5 Canvas raycasting. Tamil-themed with temples, Asuras, and mythological weapons.

## Play

Visit the GitHub Pages deployment for this repo.

## Controls

- **WASD** - Move
- **Mouse** - Look around
- **Left Click** - Fire
- **1-4** - Switch weapons
- **E** - Interact (doors)
- **ESC** - Pause

## Weapons

| # | Name | Description |
|---|------|-------------|
| 1 | Trishul | Trident melee (infinite ammo) |
| 2 | Agni | Fire shotgun |
| 3 | Sudarshana Chakra | Disc launcher |
| 4 | Brahmastra | Explosive divine weapon |

## Enemies

- **Asura** - Fast basic demons
- **Naga** - Serpent warriors
- **Rakshasa** - Heavy demons with horns
- **Mahishasura** - Level 3 Boss

## Levels

1. Kovil Vasal (Temple Entrance)
2. Irulil Nadai (Walk in Darkness)
3. Sivan Kovil (Shiva's Temple) - Boss fight

## Tech

Pure HTML5/Canvas/JS. No dependencies. Procedural audio via Web Audio API. Mobile touch controls included.
